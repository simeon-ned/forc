Control as a loop

Plant · sensors · controller · actuators.

Discrete-time picture we will use in sim: \[ x_{t+1} = f(x_t, u_t), \quad y_t = h(x_t), \quad u_t = \pi(y_t) \]

Kin / dyn as interfaces

  • FK / IK — map joints ↔ task space
  • Jacobian — velocities / force maps
  • ID / FD — torques ↔ accelerations

Prior course owns full derivations; here we only need the APIs for control.

MuJoCo stack

  • Author models in MJCF (or load URDF)
  • mjModel — constant compiled model
  • mjData — state + scratch for one instance
  • mj_step — one simulation step

Course code: practices/ + shared src/forc/

Minimal step


import mujoco

model = mujoco.MjModel.from_xml_path("scene.xml")
data = mujoco.MjData(model)
for _ in range(1000):
    data.ctrl[:] = 0.0          # open-loop
    mujoco.mj_step(model, data)
